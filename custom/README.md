# Custom Demo Plugins

Only the dashboard-facing demo plugins are kept here.

| File | Used by |
|---|---|
| `rule_based.py` + `threshold.py` | speed check preset and manual/custom dashboard workflows |
| `relative_speed.py` + `threshold.py` | two-robot relative speed preset |
| `reset_pose_effect.py` | reset service effect preset |

Manifest JSON files in `manifests/` define dashboard labels and default
constructor parameters.
