# Demo Fixtures

The demo tree contains the ROS2 fixtures used by the dashboard presets:

| File | Purpose |
|---|---|
| `common/topic_robot.py` | Publishes `/cmd_vel` for speed check and namespaced `/odom` streams for two-robot relative speed. |
| `common/reset_robot.py` | Publishes `/odom`, exposes `/reset_pose`, and alternates between effective and ineffective reset calls. |

Runtime YAML and Compose files are generated by the dashboard instead of kept
as many hand-written deployment variants.
